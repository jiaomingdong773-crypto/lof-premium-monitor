# 中国 LOF 基金实时溢价监测看板

监测 50 只热门套利 LOF（美股 QDII、原油商品、黄金贵金属、港股/海外、A股热门 LOF）的实时溢价率、申购状态与单日限额。

## 核心功能
- **自动对齐 T-2 净值日期**：美股 / 商品 QDII-LOF 自动按官方净值基准日补齐其后所有美股交易日涨跌幅。
- **盘中期货 + 汇率叠加**：结合纳指期货 (`NQ=F`)、标普期货 (`ES=F`)、WTI 原油 (`CL=F`)、黄金 (`GC=F`)、白银 (`SI=F`) 及离岸人民币 (`CNH=X`) 实时推算估值。
- **申购限额与筛选**：支持按溢价率排序、一键筛选“仅看未暂停申购”“仅看溢价 ≥ 2%”，点击任意行可查看详细计算公式。
- **零依赖运行**：纯 Python 标准库后端 + 原生前端页面，无需安装任何第三方包，本地和 Vercel 均可直接运行。

## 本地运行
```bash
python3 server.py
```
启动后在浏览器打开 http://localhost:8000 即可查看。

## 免费部署到 Vercel（公网随时访问）
1. 在 GitHub 创建一个新仓库，将本项目代码推送上去。
2. 登录 [Vercel](https://vercel.com/) -> 点击 **Add New Project** -> 导入该 GitHub 仓库。
3. 无需修改任何构建配置，直接点击 **Deploy**，约 30 秒后即可获得公网 HTTPS 访问地址。
